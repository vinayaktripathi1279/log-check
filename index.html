Cybersecurity Architectural Deep Dive

1. Regex Parsing Architecture

Extracts timestamp, targeted account, and IPv4 without third-party dependencies:

^([A-Z][a-z]{2}\s+\d+\s+\d{2}:\d{2}:\d{2})\s+\S+\s+sshd\[\d+\]:\s+Failed password for\s+(?:invalid user\s+)?(\S+)\s+from\s+([0-9]{1,3}(?:\.[0-9]{1,3}){3})

2. Sliding Window vs Total Count

A legitimate user with 5 typos over a month has 5 failures total. The 5-minute sliding window evaluates velocity: detecting 5+ failures within 300 seconds prevents false alarms on normal staff.

3. Production SIEM & Fail2ban Analogy

This Python tool mirrors how production SIEMs (Splunk, Elastic) and HIPS daemons (Fail2ban) ingest syslog events, apply velocity rules, and output actionable triage feeds.
